# Google Search Homepage Replication

A front-end recreation of Google's homepage and search interfaces, built with HTML and CSS.

The project recreates the main Google Search page, Google Image Search, and Google Advanced Search while using Google's search endpoints to perform real searches.

## Features

* Google Search homepage
* Google Image Search
* Google Advanced Search
* Functional Google Search form
* "I'm Feeling Lucky" functionality
* Navigation between all three search pages
* Advanced search with multiple search criteria
* Responsive and Google-inspired styling

## Pages

### Google Search

`index.html`

Provides:

* Standard Google Search
* "I'm Feeling Lucky" button
* Navigation to Image Search and Advanced Search

### Image Search

`image.html`

Provides:

* Google Image Search input
* Search button
* Navigation back to the main Google Search page

### Advanced Search

`advanced.html`

Provides four advanced search fields:

* **All these words**
* **This exact word or phrase**
* **Any of these words**
* **None of these words**

The form uses Google's advanced search parameters to generate the corresponding search request.

## Technologies

* HTML5
* CSS3

No JavaScript or external frameworks are required.

## Running the Project

No installation or build process is required.

Simply open `index.html` in a web browser.

## Project Goal

This project was created as a front-end exercise to recreate Google's search interface and demonstrate the use of HTML forms, URL parameters, CSS styling, and multi-page navigation.
